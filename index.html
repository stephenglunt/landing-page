Selected Projects

Selected professional work in document processing, workflow automation, and data engineering.

Handwritten Form Extraction

Celestar Holdings LLC

Status: Prototype / proof of concept

Built a document-processing prototype to extract selected fields from scanned handwritten forms. Conventional OCR struggled with handwriting and scan quality, while full-document processing with LightOnOCR was too slow on the available hardware.

I annotated sample forms and trained a YOLO model to locate relevant fields, allowing LightOnOCR to process targeted regions. I also trained a blank-field classifier to prevent extraction attempts on empty fields, addressing a source of hallucinated content. I developed and evaluated the orchestration connecting these components.

The workflow substantially reduced processing time and supported operational objectives. It remained a proof of concept and was not incorporated into standard operations.

Automated Memo Preparation

Celestar Holdings LLC

Status: In development / operational use

Built a Python workflow to automate memo preparation from information spread across multiple pages of an internal website. Manual copying was time-consuming and introduced errors and inconsistencies.

Using Requests sessions and BeautifulSoup, I implemented authenticated navigation, filtering, and data extraction through an authorized account. I created memo templates and populated them with python-docx, adding checks for missing data, standardized date formatting, and “N/A” values where requested by project officers.

I developed the entire workflow. It substantially reduced preparation time, standardized memo content, and improved accuracy. It is used operationally while development continues.

Legacy Data Migration

Celestar Holdings LLC

Status: Data migration completed

Extracted, cleaned, and transformed decades of manually entered Microsoft Access data for migration to PostgreSQL ahead of the legacy server’s decommissioning.

I brought customer stakeholders and the development team together to clarify data relationships and establish a draft database structure. As database engineers refined the schema, I provided feedback and corrections to keep it aligned with the underlying data.

Using Pandas, I addressed duplicates and inconsistent formats. Before handing off the transformed data, I instantiated PostgreSQL with the team’s current schema and imported the tables to verify compatibility. The data was successfully cleaned, transformed, and loaded.

Document-Type Classification

Celestar Holdings LLC

Status: Prototype / further development planned

Built a document-classification prototype to help organize vendor documentation across a customer’s operational files. Existing spreadsheet-based tracking had become inaccurate and outdated, making it difficult to establish which required documents were available.

I used Tesseract OCR for documents without extractable text and trained a DistilBERT model to categorize documents by their textual content. I developed the entire prototype and evaluated classification performance using accuracy, F1, and a confusion matrix.

The prototype demonstrated an approach to document categorization but has not been operationalized. Further development and use are planned.
